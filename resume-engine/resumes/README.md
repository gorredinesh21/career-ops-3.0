# Your resumes (rating set + tailoring bases)

Drop your multiple resumes here — one file per resume. Accepted:
- `*.txt` or `*.md` (paste your resume text)
- `*.pdf` (will be text-extracted)

`node lc/parse-resumes.mjs` turns each into a structured JSON
(`resume-engine/resumes/parsed/<name>.json`, same shape as `base_resume.json`).

These parsed JSONs are then used to:
1. **Rate jobs** — each job is scored against every resume; the best score wins
   and the winning resume is recorded.
2. **Tailor** — the winning resume is the starting point for the per-job
   tailored CV generated by `lc/gen-resume.mjs`.

Name files by their angle, e.g.:
- `data-engineer.md`
- `gen-ai-engineer.md`
- `mern-fullstack.md`
- `ml-engineer.md`
- `backend-go.md`
